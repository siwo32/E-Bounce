# E-Bounce

VRChatアバターの瞬きに合わせて、選択した瞳を縦・横に変形させるUnity Editorツールです。元の大きさを上限とし、標準の揺れの強さは65％です。

[BOOTH商品ページ](https://howareyu.booth.pm/items/9081219) · [お問い合わせ](https://discord.gg/cpu6ZFRJE)

このリポジトリは説明・更新情報用です。ツール本体、ソースコード、アバター素材、生成したメッシュ・マテリアルは公開しません。本体の配布先はBOOTHです。

## 必要な環境

- Unity 2022.3.22f1で検証しています。
- VRChat Avatars SDK、Modular Avatar、NDMF 1.11.0以降が必要です。
- FaceEmoは任意です。導入済みの場合は検出して連動します。後から導入した場合も、ビルド時に連携します。
- PC向けの検証です。Quest/Android向けの動作保証はありません。

検証した組み合わせ：Unity 2022.3.22f1 / VRChat SDK 3.10.3 / NDMF 1.13.1 / Modular Avatar 1.17.1 / FaceEmo 1.7.0。必要バージョンを満たすすべての組み合わせを検証したものではありません。

## 使い方

1. Unityの「MiM > E-Bounce」を開き、顔のメッシュを指定します。
2. 瞬きキーを選びます。対応する左右別キーは「L/R」の候補で扱えます。
3. 目のマテリアルを選び、UV画像上で瞳の輪郭を含む範囲を選択します。瞳サイズのシェープキーから選択することもできます。
4. 範囲を確認して元アバターへ適用します。既定では非表示のバックアップを作成します。
5. NDMF処理後のアバターで動きを確認し、シーンを保存します。

元メッシュ・元マテリアル・元のFXアセットを直接書き換えず、生成データをシーンのアバターへ反映します。シーン上のメッシュ参照は生成メッシュに置き換わります。元のPrefabへApplyしないでください。バックアップは元と同じBlueprint IDを持つため、バックアップをアップロードすると同じアバターを上書きします。

適用済みメッシュへの重ね掛けはできません。再生成は適用前のバックアップから行ってください。

## 選択と動作の注意点

- 目全体を変えるキーや、中央の瞳孔だけを変えるキーもあります。キー名だけで決めず、UV画像で瞳の輪郭と選択範囲を確認してください。
- シェープキーからの選択は表示中のマテリアルに限定されます。他マテリアルの手動選択は保持され、非表示の選択数を確認できます。
- 白目と独立ハイライトを選ばないでください。独立ハイライトの自動除外には形状による制約があります。瞳テクスチャ内に描かれたハイライトは、瞳と一緒に変形します。固定の対象は、瞳と別パーツの独立ハイライトです。
- UV0の0〜1範囲を対象とします。材質・UV・メッシュ構造によって、選択調整や適用できないケースがあります。
- FaceEmo連動には瞬き置換の設定が必要です。OSC・Face Trackingの瞬き検出は含みません。
- 既存FXの閉眼表情と競合する場合は、適用時に優先する動作を確認してください。
- アバター内の有効なE-Bounce設定は1つにしてください。重複した場合はビルドを停止します。

## 負荷と依存関係

通常の自動瞬きでは1レイヤー・1ステートを追加します。FaceEmo連動では既存の瞬きへカーブを追加します。材質スロット・頂点・分離用テクスチャが増える場合があり、描画やメモリの負荷が増加します。検証例では材質スロットが1〜3増加しました。分離用の生成テクスチャは非圧縮です。負荷ゼロを保証するものではありません。

材質分離にはlilToonまたは対応するPoiyomi材質を利用します。Poiyomiの一部の処理では、プロジェクト内の元シェーダーを生成先へ複製します。他ツール本体は配布物に同梱しませんが、MA・NDMFや使用するシェーダーへの依存があります。

他ツールが独自に制御する瞬きとの連動や、ボーンで動かす瞬きは対象外です。FaceEmoを使わず、まぶたをボーンで動かす設定のアバターでは、ビルド時にSDKの瞬きを無効にするため、まぶたの視線追従が止まります。適用済みアバターでは連携コンポーネントのWidth・Heightで強さを変更できます。新しいメッシュを作り直す場合は適用前のバックアップから再適用します。

## 検証と公開状況

1.0の公開を準備しています。Unity内の生成・連携・動画を検証し、VRChat実機での動作は作者本人が確認済みです。動作確認動画の掲載は、全アバター・すべての改変状態への対応保証ではありません。

本体の公開が確認できるまで、自動更新通知用の最新バージョンJSONは有効にしません。準備中の情報は `pending/eye_bounce_version.json` に保存し、BOOTHで同じバージョンを配布した後にルートの `eye_bounce_version.json` として公開します。

## 更新確認の通信

ツールを開いた際、UnityのセッションごとにGitHubの公開更新JSONを確認します。アバターのメッシュ・テクスチャ・設定を送信する処理はありません。更新確認に失敗しても編集を止めず、本体の自動ダウンロードや自動インストールは行いません。

## 名称変更

旧称はEye Bounceです。E-Bounceへの名称変更後も、既存設定との互換性のため内部クラス名、アセット保存先は維持します。
